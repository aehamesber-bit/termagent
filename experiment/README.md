# تجربة حوار فكري: مروان وسليم
## Intellectual Dialogue Experiment: Marwan vs Salim

تجربة حوار فعلي بين نموذجين لغويين مختلفين عبر OpenRouter، يتقمصان شخصيتين بشريتين خياليتين مختلفتين تناقشان موضوع **الحريات الدينية والحقوق الثقافية والعرقية للأقليات في الشرق الأوسط**.

---

## هيكل المشروع

```
experiment/
├── config.example.env          # نموذج ملف الإعدادات (انسخ إلى config.env)
├── dialogue/
│   ├── dialogue_ar.md          # الحوار الكامل بصيغة Markdown (ملف رئيسي)
│   ├── dialogue_ar.txt         # الحوار الكامل بصيغة نصية عادية
│   ├── dialogue.json           # الحوار كاملاً بصيغة JSON منظمة
│   └── dialogue_*.md/txt/json  # نسخ بتاريخية للتشغيلات السابقة
├── logs/
│   └── execution.jsonl         # سجل التنفيذ التقني (JSONL)
├── reports/
│   ├── execution_report.md     # تقرير التنفيذ والإحصائيات
│   └── quality_review.md       # تقرير مراجعة جودة الحوار
└── src/
    └── main.py                 # سكريبت التشغيل الرئيسي
```

## الشخصيتان

### مروان — المدافع عن المواطنة المدنية المتساوية
- **العمر:** 42 عاماً
- **الخلفية:** نشأ في مدينة متعددة الأديان والأعراق، عمل في التعليم والعمل المدني
- **الموقف:** الحقوق الأساسية متساوية للجميع؛ حياد الدولة؛ حماية الأفراد من الإكراه
- **النموذج:** `poolside/laguna-s-2.1:free` (Poolside Laguna S 2.1)

### سليم — المدافع عن الهوية المجتمعية والتعددية المتجذرة
- **العمر:** 47 عاماً
- **الخلفية:** ينتمي إلى مجتمع سرياني/مسيحي شرقي في منطقة الجزيرة، عاش تجربة تهجير جزئي
- **الموقف:** المساواة القانونية وحدها لا تكفي؛ حماية الهوية الجماعية؛ ضمانات عملية للأقليات
- **النموذج:** `nvidia/nemotron-3-ultra-550b-a55b:free` (NVIDIA Nemotron 3 Ultra)

## جودة الحوار

التقييم العام: **جيد جداً** — حوار عميق ومتماسك مع تطور حقيقي في المواقف، غير مكتمل بسبب قيود تقنية وليس جودة المحتوى.

### نقاط القوة
- ✅ **ترابط الحجج:** تطور من المبادئ المجردة → التجربة الحية → اعترافات شخصية → تخطيط عملي
- ✅ **الاستجابة المتبادلة:** كل رد يتفاعل مباشرة مع نقاط محددة من الطرف الآخر
- ✅ **انخفاض التكرار:** كل جولة تضيف زاوية جديدة
- ✅ **احترام الاختلاف:** لغة محترمة، اعتراف بنقاط قوة الخصم
- ✅ **اتساق الشخصيات:** مروان كمواطن مدني ناقد، سليم كابن أقلية عاش التجربة

### نقاط تحتاج مراجعة
- ⚠️ **ادعاءات واقعية:** إشارات تاريخية/تجربية (الآرامية، القامشلي 1998، قانون الأوقاف، الإدارة الذاتية) مقدمة كتجربة شخصية — يُنصح بالتحقق المستقل
- ⚠️ **الاكتمال الجزئي:** 8/14 جولة فقط (57%)

## تشغيل التجربة

### المتطلبات
- Python 3.9+
- `httpx` (مثبت في بيئة المشروع)
- مفتاح OpenRouter API (مجاني أو مدفوع)

### الخطوات

1. **نسخ ملف الإعدادات:**
   ```bash
   cp config.example.env config.env
   # حرر config.env وأضف مفتاح OPENROUTER_API_KEY
   ```

2. **تشغيل التجربة:**
   ```bash
   cd /workspace/app/experiment
   source config.env
   python3 src/main.py
   ```

3. **المخرجات:** ستُحفظ تلقائياً في مجلدات `dialogue/`، `logs/`، `reports/`

## ملاحظات هامة

1. **النموذجان مختلفان فعلياً:** من عائلتين مختلفتين (Poolside vs NVIDIA) مع معرّفين مختلفين على OpenRouter.
2. **لا مفاتيح في المخرجات:** مفتاح API غير مخزن في أي ملف مخرجات أو سجل.
3. **الحوار حقيقي:** جميع الرسائل ولّدت عبر استدعاءات API فعلية، ليست مكتوبة يدوياً.
4. **الشخصيتان خياليتان:** لا تمثلان جماعات حقيقية، ولا يُنسب لهما رأي أي جماعة كاملة.
5. **قيود النسخة المجانية:** معدل محدود (rate limits) على النماذج المجانية المشتركة منع إكمال 14 جولة. لإكمال التجربة، يُحتاج مفتاح OpenRouter برصيد أو حدود أعلى.
